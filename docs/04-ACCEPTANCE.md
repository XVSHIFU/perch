# 04 验收与测试计划

## 当前证据

当前源码 4 项单元测试与生产构建通过，原生与浏览器视觉未验收。新增测试不是为了覆盖现有假实现，而是验证真实文件/进程行为。

## 分层测试

- 领域单测：profile 解析、类型/版本不兼容、清单校验、差异、快照作用域、事件 revision。
- Rust 集成：临时目录安装、摘要失败、归档越界、磁盘失败、事务重启恢复、路径引用、GC 不误删。
- supervisor 集成：使用可控 fixture 子进程模拟慢启动、错误健康、崩溃、子孙进程、端口占用。与真实引擎 smoke tests 分开，不把 fixture 当真实兼容证据。
- 前端交互：使用测试 gateway 覆盖加载、空、错误、离线、任务取消、焦点与事件更新；断言用户可观察行为。
- 真实浏览器：Playwright/可用等效工具检查布局、滚动、键盘与截图；不从 jsdom 推导视觉正确。
- Windows 原生：WebView2、托盘、进程树、路径、默认浏览器、安装卸载、DPI。
- 上游 profile：在固定引擎/Web/扩展/运行时组合上跑真实启动与一个已授权最小任务；无 API 密钥则标模型任务未测，不伪造回复。

## 发布阻断用例

| 场景 | 合格结果 |
| --- | --- |
| 干净机器无 Node | 明确安装受管运行时或说明缺项，不能无提示崩溃 |
| 路径含中文/空格 | 创建、安装、日志、启动均正常 |
| 900×600 / 1024×700 / 1180×780 / 1440×900 | 导航、状态、确认/取消始终可达，无横向溢出 |
| 100/125/150% DPI、浅/深色 | 图标文字可读，弹窗不遮关键按钮 |
| Ctrl K、Esc、Tab/Shift Tab | 搜索可用，焦点限制与恢复正常，减少动画设置生效 |
| 端口占用、抢占竞争 | 有界重试，避免打开别人的服务 |
| 启动超时/中途崩溃 | 状态回到失败，日志可查，无假 running |
| 页面刷新/窗口重开 | 从后端重建真实状态，不凭 localStorage 宣称运行 |
| 重复点击启动/安装 | 单一有效任务，不产生重复进程/目录 |
| 同时运行双引擎多实例 | 配置/端口隔离，停止目标不影响其他 |
| 关闭浏览器 | Agent 服务继续由桌面管理 |
| 托盘/真正退出 | 托盘可唤回；退出停止受管进程树 |
| 管理器异常退出 | 按平台策略清理/恢复，不杀外部进程、不凭复用 PID 认领 |
| 校验失败/取消/磁盘满 | 激活版本不变，可清理或重试 |
| 安装/恢复中断电重启 | journal 可恢复到一致状态 |
| 运行中更换扩展/版本 | 先停止或阻止，不能悄悄改活动依赖 |
| 不兼容插件 | 显示具体原因，不仅显示“失败” |
| 离线 | 已安装服务可启动；目录读缓存；缺包不可伪成功 |
| 导入恶意路径/脚本/超大文件 | schema、路径和大小限制生效，未执行任意内容 |
| 克隆实例 | 配置分开；同一外部项目的风险有准确提示 |
| 恢复单个实例 | 先备份当前，只改目标受管数据，不动项目源码 |
| 导出 | 无密钥、auth 文件、会话、日志和机器绝对路径 |
| 旧缓存 GC | 被实例/快照引用的工件仍可恢复 |
| 安装升级卸载 | 用户数据策略明确，更新不丢失实例 |

## 性能预算（目标，尚无实测结论）

- 管理窗口不得等待引擎安装才能可交互；耗时任务在后台。
- 首屏目标在约定测试机器上 ≤2 秒进入可操作状态，单独记录冷/热启动，不把上游首次安装计入。
- 日志需有容量上限与批量刷新；模拟持续输出时窗口仍能切页/停止任务。
- 对大目录使用分页/虚拟列表，避免一开始为 4 个示例卡片引入复杂优化。

## 验证报告格式

记录 commit、Windows/CPU/内存、Node/Rust/WebView2、profile ID、版本/摘要、执行命令、预期/实际结果、日志路径/截图、pass/fail/not-run。可复现失败先保留证据，再修复。通过与未执行分列，禁止把 Linux build 记为 Windows pass。
